# The Bookmark Cafe — Local Business Website

A modern, responsive local-business website concept created for **The Bookmark Cafe, Kalyan** as part of **Future Interns – Full Stack Web Development Task 3**.

The goal of this project is to provide a local café with a professional online presence where customers can discover the café, explore the menu, find the location, and contact the business easily.

## 📸 Project Overview

The website is designed as a modern café website with a warm, minimal and responsive user interface.

It includes:

- Hero section with clear call-to-action buttons
- Café story / about section
- Interactive food and drink menu
- Menu category filtering
- Café gallery
- Contact information
- Phone call CTA
- Location and directions
- Mobile-responsive navigation
- Business-focused call-to-action sections
- GitHub Pages deployment

---

## ✨ Features

### 🏠 Hero Section

- Strong café branding
- Short introduction
- "Explore Menu" CTA
- "Find Us" CTA
- Café rating and cuisine information

### 📖 Our Story

- Introduction to the café
- Brand-focused content
- Key business information
- Customer-oriented messaging

### 🍕 Interactive Menu

Visitors can filter menu items by category:

- All
- Pizza
- Pasta
- Coffee & Drinks
- Momos
- Dessert

The menu filtering functionality is implemented using JavaScript.

### 🖼️ Gallery

A visual section designed to showcase:

- Food
- Coffee
- Café atmosphere
- Customer experience

### 📍 Visit Us

Includes:

- Café address
- Phone number
- Opening hours
- Google Maps directions
- Instagram CTA

### 📱 Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile devices

### ⚡ JavaScript Interactivity

JavaScript is used for:

- Mobile navigation
- Menu category filtering
- Scroll reveal animations
